Prototype built on a synthetic dataset schema-matched to NOAA's public Marine Microplastics Database (NCEI) — real-file swap-in supported. Elevated-risk threshold is data-derived (75th percentile of sampled concentration). This tool is a software-first prioritization layer intended to guide where limited monitoring/cleanup resources go — it complements, and does not replace, direct sensor-based detection.
